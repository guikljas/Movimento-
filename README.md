# Davi — Estudo Cinematográfico

Experiência web 3D construída a partir dos modelos fornecidos em `teste 01.zip`.

## Como executar

Abra a pasta em um servidor HTTP local (por exemplo, com a extensão *Live Server* do VS Code) e acesse `index.html`. Isso é necessário para o navegador carregar os arquivos `.gltf` e `.bin` corretamente.

## Controles

- Arraste a escultura para alterar o ângulo.
- Use a roda do mouse ou gesto de rolagem para aproximar e afastar.
- Alterne entre **Busto** e **Corpo inteiro**.
- Ative ou desative a malha de contornos e a rotação automática.

## Créditos dos modelos

Os modelos incluídos permanecem sob a licença CC-BY-4.0 indicada nos arquivos `models/models/*/license.txt`. A autoria e as fontes originais estão registradas nos próprios arquivos `.gltf`.
